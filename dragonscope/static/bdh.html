The Dragon Hatchling How a BDH model works Back to the DragonScope demo

Its memory is in its connections.

BDH is a language model built from neurons and synapses. Its learned weights stay fixed as it reads. What it remembers is held in synapses that strengthen when neurons fire together.

  1. Read The next character becomes the input signal.
  2. Fire The signal excites some neurons. Activity is positive, and the rest stay silent. x = relu(signal · E)
  3. Wire together Neurons that passed a signal strengthen their links to neurons that fire next. σ(i, j) += y(i) · x(j)
  4. Recall Firing neurons query that memory, which returns what earlier characters stored there. y = relu(LN(ρ · x) · Eᵥ)
  5. Pass it on Only neurons both excited and recalled send a signal to the next round. signal = LN(signal + LN((x ⊙ y) · D))

This is a real BDH, calculated live in your browser, but a tiny untrained one. With random weights it reads without understanding, so it shows the mechanism and not language skill. Its equations match the published code, without the rotation by position in the formulas shown. The four arcs are its heads. Synapses are drawn from the paper's σ rule; the code keeps them in a compressed form, ρ.
